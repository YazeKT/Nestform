# Nestform and Yaze Media brand usage

The software licence and the product identity are separate. GPL-3.0 grants rights in the program source and binaries. It does not grant permission to suggest that a modified build is an official Nestform or Yaze Media release.

The Nestform name, fitted-shape N logo, wordmark, application icon, and Yaze Media name are product identifiers used by Kirsten Trimaley, trading as Yaze Media. No registered trade-mark status is claimed.

## Allowed use

- Redistribute an exact, unmodified release published by `YazeKT/Nestform` with its original identity and notices.
- Refer truthfully to compatibility or origin, such as “based on Nestform” or “a fork of Nestform.”
- Show the interface or logo in factual reviews, tutorials, issue reports, and attribution.
- Use the project name to link to or discuss the official repository.

## Modified distributions

A materially modified distribution must use a different product name and application icon, clearly identify its maintainer, and state that it is unofficial. It must not imply endorsement by Kirsten Trimaley or Yaze Media.

This brand policy does not prevent anyone from exercising GPL-3.0 rights in the code. If a brand-use term conflicts with a right granted by GPL-3.0, the GPL controls the software right; this document only addresses source identification and misleading brand presentation.
