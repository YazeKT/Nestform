# Support

## Questions

Use [GitHub Discussions](https://github.com/YazeKT/Nestform/discussions) for setup and workflow questions. Read the [User guide](docs/USER-GUIDE.md) and [Troubleshooting](docs/TROUBLESHOOTING.md) first.

## Bugs

Use the GitHub bug form and include the Nestform version, Windows version, exact steps, expected and actual behavior, and a minimal non-confidential sample when possible.

## Feature requests

Use the feature form to explain the manufacturing workflow, user need, and acceptance criteria. Proposals that replace or change engine behavior need separate parity evidence.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Direct contact

For client support or a matter that cannot be shared publicly, email [kirstentrimaley@gmail.com](mailto:kirstentrimaley@gmail.com). Never send production drawings containing confidential information unless explicitly arranged.
