# How to use Nestform

## Auto Nest — recommended

1. Click Auto Nest when Nestform opens.
2. Choose one or more scaled SVG drawing files. Auto Nest starts a fresh job only after files are selected.
3. Enter the sheet width, sheet height and number of sheets in millimetres.
4. Review the automatic setup and click Start Auto Nest. The default clearance is exactly 3 mm and six evenly spaced rotations are enabled.
5. Watch the live remaining-time countdown, progress and evaluated candidate count. You can stop early and keep the best result found so far.
6. Select a result and sheet in the right rail, then export at exact physical scale.

## Manual workflow

1. Rename the job beside the Nestform logo so saved history is easy to recognise.
2. Click Import, then choose whether to add parts to the current nest or create a fresh nest.
3. Set each part quantity. Dimensions are shown in the selected unit.
4. Add every full sheet and offcut you can use. Give each stock size its own quantity.
5. Set the exact part spacing and allowed rotations. For scaled work, leave units on millimetres and SVG units per inch on 72.
6. Choose a run duration and start nesting. Progress, remaining time and candidate count are live.
7. Inspect result and sheet previews in the right rail. The engine searches all available stock and keeps improving the layout until stopped or time reaches zero.
8. Export the selected result.

## History and backup

Completed results remain in History with their date and time and can be previewed or exported again. In Settings, open History & backup and choose a folder. Nestform then writes a physical-size SVG and a job record there for every completed nest, including entries already in local History.

## Canvas controls

- Ctrl + zooms in.
- Ctrl - zooms out.
- Ctrl 0 fits the full sheet to the canvas.
- The mouse wheel zooms and dragging pans.

SVG processing and nesting run locally. DXF and CDR conversion uses the configured online service only after confirmation.
