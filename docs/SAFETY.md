# Safety and production use

Nestform prepares geometry; it does not operate cutting machinery. Inspect every exported drawing before production. Confirm units, material size, kerf or part spacing, contour closure, scale, and machine-specific settings in the software that drives the cutter.

Keep original source files. Use History as a convenience rather than the only archive. Complex or damaged input can produce an unusable layout; stop the run, correct the source drawing, and try again.

DXF and CDR conversion sends the chosen file to the configured conversion service after a confirmation prompt. SVG nesting and export stay local.
