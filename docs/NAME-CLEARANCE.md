# Product-name clearance status

Nestform is the current provisional product name. It is not represented as a registered trade mark.

A preliminary public web search found active third-party uses of “Nestform,” including another software product. This search is not a formal legal clearance and does not determine registration classes, territories, likelihood of confusion, or enforceable rights.

Before broad commercial promotion or a registration application, the maintainer should commission or conduct an appropriate search covering:

- South African CIPC records and the relevant software and service classes
- WIPO Global Brand Database records
- Relevant national registers in intended sales territories
- Company names, domains, application stores, and unregistered market use

Until that work is complete, project materials must use the plain name without `®`, must not claim registration, and must not state that the name is globally exclusive.
